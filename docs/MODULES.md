# Modules

Current UI modules: dashboard, studio, library, shared shell, and global player. Placeholder routes reserve beats, community, store, marketplace, AI, releases, analytics, and settings without implementing their future domain logic.

Future domain boundaries:

- Catalog and content: platform content records, intentional uploads, required metadata, and publication state.
- Tags: explicit creator/admin metadata and validation, separate from technical file inspection.
- Preview: derived audio/video previews, waveforms, thumbnails, and technical metadata.
- Shorts: short-form vertical multimedia discovery linked to creators and platform content.
- Streaming: tracks and listening experiences.
- Marketplace: products, licensing, checkout, ownership, payouts, and review.

These are conceptual boundaries only in Phase 2. Do not implement backend storage, media processing, feeds, recommendations, comments, likes, payments, or authentication yet.
