# Profile cover presets

Three AI-generated studio photographs created for BeatVault profile covers on 2026-10-08.
These bundled presets do not depict the account owner's actual studio or uploads.
Original generation resolution: 2172 x 724 pixels. No external image requests are needed.

The original PNG masters are retained in this folder. The app serves 1600 x 533 WebP
derivatives (quality 86) to reduce transfer size while preserving the cover composition.
